# Hosting Bilgi Formu

Asagidaki bilgileri doldurun, deploy islemini tamamlayalim. Her madde tek bir
cumle ile aciklanmistir.

## 1. Host paneli
Hangi paneli kullaniyorsunuz? (cPanel, Plesk, hPanel, veya farkli bir panel.)

## 2. Sunucu yazilimi
Sunucuda hangi web sunucusu calisiyor? (Apache, LiteSpeed, Nginx, veya bilmiyorum
seklinde cevap verebilirsiniz; hosting firmasina sorarak ogrenebilirsiniz.)

## 3. PHP mevcudiyeti
Sunucuda PHP var mi? (Bazi statik hosting planlarinda PHP kapalidir; bu durumda
`.htaccess` bazi ozellikleri calistirmaz.)

## 4. Domain adi
Site hangi adreste yayinda olacak? (Ornegin: kocaelisocialhub.com veya
www.kocaelisocialhub.com. www ile mi, yoksa www olmadan mi calismasini
istiyorsunuz?)

## 5. DNS yonetimi
DNS kayitlari nerede yonetiliyor? (Domain firmasinda, hosting firmasinda, veya
farkli bir yerde. DNS neredeyse A kaydini orada degistirirsiniz.)

## 6. SSL durumu
SSL sertifikasi aktif mi? (cPanel'de AutoSSL calistirdiniz mi? Veya manuel
bir sertifika yuklediniz mi? Henuz SSL yok mu?)

## 7. Erisim yolu
Dosyalari nasil yukleyecegiz? (cPanel File Manager, FTP, SSH, veya Git.
Hangi yontemi kullanabilirsiniz?)

## 8. Iletisim
Degisiklik sonrasi haberlesme icin hangi e-posta adresini veya iletisim
formunu kullanalim?
